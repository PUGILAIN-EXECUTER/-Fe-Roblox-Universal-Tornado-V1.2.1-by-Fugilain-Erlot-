# -Fe-Roblox-Universal-Tornado-V1.2.1-by-Fugilain-Erlot-
  Tornado V.1.2.1
Tornado V.1.2.1 is a powerful script designed to rotate parts around you. With this script, users can easily control the movement of parts, creating dynamic, rotating effects. The script allows for fine-tuning the distance between the rotating parts and the center, providing flexible control over the rotation speed and radius.

Key Features:
Rotating Parts: Allows you to rotate all parts around a central point, perfect for creating swirling or tornado-like effects in your environment.
Adjustable Distance: You can easily adjust the distance of each part from the center, giving you full control over the size and speed of the rotation.
Version 1.2.1: Includes bug fixes and performance improvements, ensuring smooth operation and flexibility.
How It Works:
Simply run the script, and it will automatically make the parts rotate around the central point.
Use the adjustable distance parameter to control how far the parts are from the center, allowing for a custom setup.
Perfect for game development, visual effects, or any project that requires dynamic, rotating elements!
